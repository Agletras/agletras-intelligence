# AI Agent Rules

1. Read the relevant docs before editing.
2. Work only in the new Agletras project. Never modify the original repository/site.
3. Do not push, publish, or deploy without explicit owner approval.
4. Preserve the supplied leaf logo exactly.
5. Treat the Ethiack ZIP as a reference, not permission to copy. Reuse code/assets only after documented rights review; otherwise independently implement interaction concepts.
6. Do not fabricate clients, testimonials, metrics, certifications, research results, or capabilities.
7. Every task must state allowed files, forbidden files, acceptance criteria, and tests.
8. Never assign concurrent agents the same writable files. Shared configuration has one owner at a time.
9. Run actual checks and report exact results; do not claim tests passed if not run.
10. Core content must work without WebGL/video and with reduced motion. Use semantic HTML, keyboard support, visible focus, and touch-friendly controls.
11. Update docs/CHANGELOG when material decisions or behavior change.
12. Handoff: summary, files changed, decisions/ADR, commands/results, unrun tests, risks, next task.
